A dynamic digital clock built with React and Vite. The application displays the current date and time, updating automatically every second.
Features
- Displays the current time in a 12-hour format.
- Displays the current date in a readable format.
- Automatically updates every second.
- Uses date-fns for date and time formatting.
- Responsive glassmorphism-inspired design.
- Colorful interface with glowing accents.
Technologies Used
- React
- JavaScript (JSX)
- Vite
- date-fns 2.30.0
- CSS3
Installation
Clone the repository:
git clone njugunamark310@cloud
Navigate into the project:
cd color-clock
Install dependencies:
npm install
Start the development server:
npm run dev
Open the local URL provided by Vite in your browser.
